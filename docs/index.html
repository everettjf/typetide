§ THE FINE PRINT

Everything you'd want.
Nothing you don't.

01

Works across your apps

Reads your selection through macOS Accessibility or Windows UI Automation, with a synthetic-copy fallback for Electron & web apps — then restores the previous clipboard. Protected fields and apps that block selection or paste may not work.

02

Privacy you can reason about

The built-in model and local Ollama keep triggered selections on your machine. The built-in model needs a one-time download before offline use. A cloud backend sends them to the endpoint you configure. Accessibility/UI Automation enables system-wide selection access; clipboard fallback briefly copies and then restores your clipboard, which clipboard-history tools may record.

03

Undo-safe rewrite

Rewrites are pasted in place and preserve each app's native undo stack. Changed your mind? Use ⌘Z or Ctrl+Z.

04

Shortcuts that fit your workflow

Set smart or fixed language direction independently for Read and Write. Change either shortcut, clear one completely, or trigger Read from the floating icon and automatic selection mode.

05

Translate faithfully, or choose a writing style

The built-in model supports Faithful translation and in-place replacement. For Formal, Casual, or Polished rewriting, choose Ollama or an API backend.

06

Native on both platforms

A SwiftUI menu-bar app on macOS and a Win32 tray app on Windows. No Electron runtime, with launch at login and a per-app skip list.

§ YOUR MODEL

Local or cloud.

Start with the built-in offline model on Apple Silicon. Choose Ollama or an API on either platform when you need another model or writing style.

Apple Silicon Mac · default

Built-in offline model

Download TranslateGemma 4B once (about 2.22 GB), then translate on your Mac. No account, API key, Ollama, or Python setup. Pause and resume across restarts, with download speed and time estimates, automatic retries, and integrity checks. Allow about 4.5 GB free during installation.

Faithful translation and in-place replacement. Long selections above the model’s 2K input-token limit need to be shortened.

Mac + Windows · local

Ollama

Offline and private. Install a model and go — TypeTide auto-picks an installed one if your configured model isn't there.
